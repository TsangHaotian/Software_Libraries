# Software Libraries

个人整理的实用软件集合，涵盖系统工具、磁盘管理、多媒体处理。

## 软件列表

| 目录 | 功能 |
|------|------|
| ChipGenius | USB 设备芯片检测工具 |
| DiskGenius | 磁盘分区和数据恢复 |
| Empty_folder_cleanup | 空文件夹清理 |
| LastActivityView | 系统操作记录查看器 |
| QianQianMusic | 高品质音乐播放器（千千静听） |
| Winzip | 经典压缩工具（绿色版） |

## 使用方式

```bash
git clone https://github.com/你的用户名/Software_Libraries.git
```

各软件文件在对应目录中，直接运行即可。

## 环境要求

- Windows 7 / 10 / 11
- .NET Framework 4.5+（部分工具需要）
- 管理员权限（磁盘工具需要）

## 许可

各软件遵守其原作者的许可协议，本仓库仅作收集整理。
